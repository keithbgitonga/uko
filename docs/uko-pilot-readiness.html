Executive summary

The MVP is functionally complete for an internal pilot in one Nairobi zone: rider and driver Android apps, matching, scheduling, recurring rides, calendar suggestions, cash + simulated M-Pesa payment, safety/SOS, trip history, driver earnings/shift, dispatch console and a Postgres-backed API have all been exercised end-to-end on the test bench.

It is not ready for public beta. The remaining gaps are integration and operations, not core product flows: real M-Pesa Daraja, maps/location, push notifications, SMS OTP delivery, dispatch role-based access, incident response staffing/runbook, observability and legal/security hardening.

Scope of this review

Covered: rider app, driver app, dispatch console, API, local Postgres, test bench and the operational model for the pilot. Out of scope for this review: detailed pricing economics, marketing, regulatory licensing beyond data protection, and the V0.2 roadmap (cards, automated payouts, iOS, ride-check, price bidding).

4. Internal-pilot go/no-go checklist

Product & engineering

  • SMS OTP provider live with rate limits
  • Daraja sandbox STK + callback verified (or cash-only decision signed off)
  • Google Maps key + location permissions (or zone-address fallback)
  • FCM push for offers/trip/SOS
  • Dispatch ops role + audit log
  • Signed release builds installed on pilot devices
  • Crash reporting + core analytics events
  • Server metrics, alerts and on-call contact
  • Postgres backup + restore drill
  • Versioned API + release notes

Operations & compliance

  • Responder agreement + on-call rota + SOS drill
  • Incident/refund runbook and support channel
  • Driver vetting: licence, insurance, vehicle, documents
  • Rider pilot invite list + onboarding script
  • Cash handling and reconciliation process
  • Privacy policy, terms and DPA signed
  • Data retention + PII handling policy
  • Pilot KPIs and daily review cadence
  • Zone map and approved pickup points
  • Go/no-go meeting with sign-off below
Pilot definition (proposed). One Nairobi zone · 15–25 riders · 8–12 Bodas · 4 weeks · Boda only · cash-first with M-Pesa after Daraja passes · no cancellation fee · ~20% commission · private responder model (no 999 dialling). KPIs: assignment < 3 min, completion ≥ 90%, cancellation ≤ 10%, zero unresolved safety incidents, CSAT ≥ 4.5/5, daily reconciliation complete.
